Aide HopHop

HopHop est un atelier de recettes de bière : conception, calculs, bibliothèque d’ingrédients, brassages et exports. Sur BrassageAmateur, il s’intègre au forum et à BrewRecipes.

1. Démarrer

HopHop se présente comme une application web en onglets :

  • Recettes — liste, création, import
  • Brassins — historique des brassages
  • Ingrédients — bibliothèque (malts, houblons, levures, divers, styles)
  • Matériel — profils d’équipement
  • Compte — avatar, thème, unités, sauvegarde

L’enregistrement est automatique après quelques secondes (« Enregistré » en haut à droite). Une notification signale les erreurs éventuelles.

2. Recettes et éditeur

  • + Nouvelle recette — crée une fiche vide avec le premier profil matériel.
  • Importer BeerXML / BeerJSON — ajoute une ou plusieurs recettes (et crée au besoin les ingrédients et le profil d’équipement).
  • Cliquez une fiche recette pour ouvrir l’éditeur : nom, style, volume, rendement, eau/grain, fermentescibles, houblons, levure, divers, empâtage, fermentation, notes.
  • Redimensionner — multiplie les quantités pour un nouveau volume final (sur place ou en copie).
  • Dupliquer / Supprimer — en bas de l’éditeur.
  • Fiche recette — vue imprimable ; Enregistrer un brassage — bascule vers l’historique.

3. Calculs

Le panneau latéral (ou sous la recette sur petit écran) met à jour en direct :

  • densités (DI / DF), ABV, IBU (Tinseth), couleur (EBC / Morey)
  • volumes d’eau (empâtage, rinçage, pré-ébullition…)
  • sucre de conditionnement selon le CO₂ visé
  • prix de revient estimé si des prix sont renseignés en bibliothèque

Unités européennes : L, kg, g, °C, EBC, densité en SG (et Brix en affichage secondaire selon vos préférences).

4. Ingrédients, styles et stock

Chaque compte a sa bibliothèque personnelle. Les recettes y font référence par nom / identifiant interne.

  • Onglets : fermentescibles, houblons, levures, divers, styles.
  • Importer bibliothèque — BeerXML ou BeerJSON (ex. guide BJCP) pour charger beaucoup d’entrées d’un coup.
  • Archivage : un ingrédient retiré reste utilisable dans les recettes déjà liées ; restaurez-le via « Voir les archivé(s) ».
  • Stock — quantités suivies ; alertes de manque à la conception.

Sur le forum BrassageAmateur, vous pouvez aussi prendre un style depuis le catalogue BrewRecipes sans importer tout le BJCP.

5. Profils matériel

Un profil décrit votre installation : volume final, durée d’ébullition, évaporation, pertes trub / empâtage, absorption des drêches, rapport eau/grain, température d’infusion, contraction, rendement.

Chaque recette pointe vers un profil ; le rendement et le rapport eau/grain restent modifiables par recette.

6. Brassins

Depuis une recette, Enregistrer un brassage (ou Brassins → Nouveau brassage) crée une entrée « vide » : vous choisissez surtout la date (et éventuellement la sortie de stock). Les stats visées et une copie de la recette sont figées. Ensuite, dans l’onglet Brassins, Modifier permet de saisir DI / DF, volume, notes, dégustation, etc. L’historique compare le prévu et le réel (ABV, atténuation, rendement).

6.1 Autres notes (optionnel)

Dans Compte → Brassins, activez Autres notes pour afficher un sous-formulaire dépliable à l’édition d’un brassage. Désactivé par défaut ; un rappel sous le formulaire d’édition pointe vers Compte si besoin. Si vous désactivez l’option plus tard, les saisies déjà enregistrées restent en mémoire.

Les colonnes « prévu » viennent de la recette figée au moment de l’enregistrement du brassage. Vous ne saisissez que les valeurs réelles du jour.

  • Quantités — un tableau liste les fermentescibles, houblons, levures et divers de la recette (Q prévu / Q réel). Une ligne vide en bas et le bouton + Ingrédient permettent d’ajouter un élément non prévu (nom, unité, quantités).
  • Températures (°C) — strike, paliers d’empâtage, rinçage (78 °C), ébullition (100 °C), après ébullition, après refroidissement (température de levurage prévue si renseignée).
  • pH — mesures à température ambiante (~20 °C), avec fourchettes indicatives sous chaque ligne (ex. maische 5,2–5,6 ; eau de rinçage ≤ 6,0). Ce sont des repères de brassage amateur, pas un calcul d’eau HopHop.
  • Densités — avant rinçage, avant / après ébullition (prévu calculé quand c’est possible).
  • Volumes (L) — avant rinçage, eau de rinçage, avant / après ébullition, fermenteur, conditionnement.
  • Notes libres — champ texte pour le reste du journal de brassage.

Les densités principales DI / DF mesurées restent dans la partie haute du formulaire (elles servent au calcul d’ABV, d’atténuation et de rendement réel).

7. Fiche recette et exports

  • Fiche recette — mise en page pour impression (avec ou sans étapes, prix de revient optionnel).
  • Exporter BeerXML 1.0 / BeerJSON 1.0 — copie ou téléchargement du fichier.

8. Compte et préférences

  • Thème (vert, ambre, blé, myrtille, sombre) et densité d’affichage
  • Unité de densité principale (SG ou Brix) et formule réfractomètre
  • Brassins — activer / désactiver le sous-formulaire Autres notes
  • Avatar (emoji / photo locale ; sur le forum, avatar phpBB par défaut)
  • Export / import de la sauvegarde JSON du compte (mode autonome surtout)

9. Intégration BrewRecipes et forum

Sur BrassageAmateur, HopHop vit sous le forum (/forum/hophop/). Ce chapitre décrit ce qui change par rapport à une installation autonome.

En résumé

  • Vous êtes connecté avec votre compte forum (pas de compte HopHop séparé).
  • Vos recettes sont stockées en MySQL, une fiche JSON par membre.
  • Vous pouvez envoyer une recette vers BrewRecipes et ouvrir une fiche BrewRecipes dans HopHop.
  • Les styles du catalogue BrewRecipes sont disponibles à la demande pour être ajoutés à une recette dans HopHop.

9.1 Authentification phpBB (SSO)

  • HopHop lit la session forum : même cookie, même identité.
  • Si vous n’êtes pas connecté au forum, HopHop propose le lien de connexion phpBB.
  • « Retour sur le forum » remplace la déconnexion HopHop locale.
  • L’avatar affiché est celui du profil forum (sauf photo HopHop importée en override).

9.2 Stockage MySQL

  • Table {préfixe}hophop_store : une ligne par user_id, colonne store_json (tout le compte : recettes, bibliothèque, brassins, préférences).
  • Les données sont personnelles : importer le BJCP ou une recette ne les partage pas aux autres membres.
  • Si un ancien fichier data/store/<pseudo>.json existe, il peut être migré une fois vers MySQL au premier chargement.

9.3 Styles depuis BrewRecipes

Dans l’éditeur, à côté du menu Style :

1
Depuis BrewRecipes… — ouvre le dialogue.
2
Choisissez un guide (ex. BJCP 2021).
3
Parcourez la liste, puis Choisir ce style.

HopHop copie alors le style dans votre bibliothèque (nom, guide, plages OG/FG/IBU/EBC/ABV…) et l’associe à la recette. Aucun catalogue global n’est écrit dans la table HopHop pour tous les users.

9.4 Export / import de recettes avec BrewRecipes

Sens Où Ce qui se passe
HopHop → BrewRecipes Éditeur → Partager sur BrewRecipes Envoi du BeerXML (POST), file d’import BrewRecipes, ouverture de l’écran d’aperçu / association de style comme un import classique.
BrewRecipes → HopHop Fiche recette BrewRecipes (desktop) → Ouvrir dans HopHop Récupération du BeerXML, envoi vers HopHop, import dans votre compte et ouverture de l’éditeur. Le bloc STYLE du fichier est aussi enregistré en bibliothèque.

Les deux sens exigent d’être connecté au forum. Le bouton HopHop côté BrewRecipes n’apparaît que s’il existe un fichier BeerXML pour la fiche (et, pour l’instant, sur la vue desktop des actions auteur).

9.5 Schéma rapide

Forum phpBB (session)
        │
        ├─► HopHop (/forum/hophop/)
        │      • auth = session forum
        │      • données = MySQL hophop_store
        │      • Partager → BeerXML → BrewRecipes (aperçu import)
        │      • Styles ← AJAX catalogue BrewRecipes
        │
        └─► BrewRecipes (extension)
               • Ouvrir dans HopHop → BeerXML → éditeur HopHop

9.6 Mode autonome (hors forum)

Sans intégration phpBB, HopHop reste utilisable en solo : comptes locaux, fichiers JSON sous data/, pas de boutons BrewRecipes ni d’avatar forum. Cette aide s’applique surtout à la version BrassageAmateur.

10. Limites et conseils

  • La bibliothèque et les styles restent par compte : chacun importe ou choisit ce dont il a besoin.
  • Un BeerXML incomplet côté BrewRecipes donnera un import HopHop incomplet — utilisez au besoin « Réparer / exporter » dans BrewRecipes avant d’ouvrir dans HopHop.
  • Sur mobile, HopHop fonctionne ; le bouton « Ouvrir dans HopHop » depuis BrewRecipes est pour l’instant réservé à la fiche desktop.
  • Gardez une sauvegarde (export JSON Compte, ou dump MySQL côté admin forum).
